# Quickstart

This hands-on guide walks you through creating, configuring, and executing your first conversational AI agent using `chatflow-agent`.

---

## 1. Create a Basic Agent

In `chatflow-agent`, an **`Agent`** represents a persona with dedicated instructions and capabilities, while the **`Runner`** orchestrates conversational turns and tool evaluation loops.

Create a new file named `quickstart.py`:

```python
import os
from chatflow_agent import Agent, OpenAIEngine, Runner

# 1. Initialize the LLM provider engine
engine = OpenAIEngine(
    model="gpt-4o",
    api_key=os.getenv("OPENAI_API_KEY"),
)

# 2. Define the agent persona and instructions
agent = Agent(
    name="Assistant",
    instructions="You are a concise and helpful AI technical assistant.",
    engine=engine,
)

# 3. Initialize the Runner with your starting agent
runner = Runner(starting_agent=agent)

# 4. Execute a conversational turn
response = runner.run(
    session_id="quickstart_session",
    user_message="Explain reactive programming in two concise sentences.",
)

# 5. Display the output
print("Agent Response:")
print(response.content)
```

Run the script from your terminal:

```bash
python quickstart.py
```

<Callout type="info" title="Event Loop Guard">
<code>runner.run()</code> is a synchronous convenience method designed for scripts and CLI utilities. If you are inside an existing asynchronous event loop (e.g. FastAPI, Jupyter Notebook, or asyncio), use <code>await runner.run_async()</code> instead. Calling <code>runner.run()</code> inside an active loop raises a clear <code>RuntimeError</code>.
</Callout>

## 2. Adding Tools with `@tool`

Agents become exponentially more powerful when given access to deterministic functions. Use the `@tool` decorator to turn any Python function into an introspectable tool:

```python
import os
from chatflow_agent import Agent, OpenAIEngine, Runner, tool

# 1. Define a tool with typed parameters and docstrings
@tool(name="calculate_discount", description="Calculate discounted price from original amount and percentage.")
def calculate_discount(price: float, discount_percent: float) -> str:
    """Calculate the final price after applying a percentage discount.

    Args:
        price: The original price in dollars.
        discount_percent: The percentage discount to apply (e.g. 15 for 15%).
    """
    savings = price * (discount_percent / 100.0)
    final_price = price - savings
    return f"Original: ${price:.2f}, Savings: ${savings:.2f}, Final Price: ${final_price:.2f}"

# 2. Attach the tool to the Agent
engine = OpenAIEngine(model="gpt-4o", api_key=os.getenv("OPENAI_API_KEY"))

agent = Agent(
    name="SalesBot",
    instructions="You help customers with purchase calculations. Always use calculate_discount for math.",
    engine=engine,
    tools=[calculate_discount],
)

runner = Runner(starting_agent=agent)

# 3. Ask a question requiring tool execution
response = runner.run(
    session_id="sales_session_1",
    user_message="What is the final price for a jacket priced at $120 with a 25% discount?",
)
print(response.content)
```

### Inspecting Tool Execution

The returned `AgentResponse` object retains full transparency into the conversational turn:

```python
# Inspect executed tool calls
for call in response.tool_calls_executed:
    print(f"Tool executed: {call.name} with arguments: {call.arguments}")
```

## 3. Asynchronous Execution with `Runner.run_async`

For high-concurrency web services, chatbots, and event loops, use the native asynchronous API:

```python
import asyncio
import os
from chatflow_agent import Agent, OpenAIEngine, Runner

async def main() -> None:
    engine = OpenAIEngine(
        model="gpt-4o",
        api_key=os.getenv("OPENAI_API_KEY"),
    )

    agent = Agent(
        name="AsyncBot",
        instructions="Provide concise answers.",
        engine=engine,
    )

    runner = Runner(starting_agent=agent)

    # Asynchronous turn
    response = await runner.run_async(
        session_id="async_session_1",
        user_message="List three key advantages of asynchronous Python.",
    )

    print(response.content)

if __name__ == "__main__":
    asyncio.run(main())
```

## 4. Multi-Provider Flexibility

Because `chatflow-agent` uses direct REST engines, switching between providers is instantaneous without changing your agent logic:

```python
import os
from chatflow_agent import Agent, AnthropicEngine, GeminiEngine, OpenAIEngine

# OpenAI
openai_engine = OpenAIEngine(model="gpt-4o")

# Anthropic Claude
anthropic_engine = AnthropicEngine(model="claude-3-5-sonnet-20241022")

# Google Gemini
gemini_engine = GeminiEngine(model="gemini-2.0-flash")

# Groq / Ollama / DeepSeek via OpenAI-compatible REST endpoint
groq_engine = OpenAIEngine(
    model="llama-3.3-70b-versatile",
    base_url="https://api.groq.com/openai/v1",
    api_key=os.getenv("GROQ_API_KEY"),
)
```

<Callout type="warn" title="Provider Differences in v0.3.4 vs v0.4.0rc1">
In <VersionBadge version="0.3.4" status="stable" />, <code>GeminiEngine</code> relies on the <code>google-genai</code> package. In <VersionBadge version="0.4.0rc1" status="prerelease" />, <code>GeminiEngine</code> was refactored to pure HTTP REST via <code>httpx</code>, eliminating external Google SDK dependencies.
</Callout>
