# chatflow-agent Documentation

Welcome to the official documentation for **chatflow-agent**, a lightweight and reactive Python framework designed for building robust, stateful conversational AI agents.

## Key Capabilities

- **Reactive State Machine**: Manage complex multi-turn dialogs with clean state transitions.
- **Schema Validation**: Strongly-typed payload and action handling powered by standard typing.
- **Pluggable Architecture**: Seamlessly integrate custom tools, LLM providers, and memory stores.
- **Production-Ready**: Engineered for low-latency cloud and edge deployments.

## Quick Installation

```bash
pip install chatflow-agent
```

> **Note**: Current stable release is `v0.3.4`. Prerelease candidate `v0.4.0rc1` is available for testing upcoming features.
