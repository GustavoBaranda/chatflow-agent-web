# chatflow-agent Documentation

Welcome to the official documentation for **chatflow-agent**, a lightweight, async-first Python framework engineered for building modular conversational agents and multi-agent swarms with native, type-safe handoffs.

Created and led by **Gustavo Baranda** alongside an international open-source community, `chatflow-agent` is designed to eliminate framework bloat and vendor lock-in while providing enterprise-grade concurrency, resilient memory, and multi-channel connectivity.

## Release & Versioning Strategy

`chatflow-agent` strictly adheres to Semantic Versioning (SemVer). The documentation is version-aware:

* <VersionBadge version="0.3.4" status="stable" /> **Current Stable Release (Default):** Recommended for all production deployments. Published on PyPI on October 23, 2026.
* <VersionBadge version="0.4.0rc1" status="prerelease" /> **Prerelease Candidate 1:** Available on PyPI for testing upcoming architecture enhancements, including REST-native Gemini execution and swarm duplicate validation.

```bash
# Install stable release (default)
pip install chatflow-agent

# Install prerelease candidate
pip install "chatflow-agent==0.4.0rc1"
```

<Callout type="info" title="Stable-First Documentation">
All code snippets and API signatures in this documentation default to the stable <code>v0.3.4</code> release. Enhancements or breaking changes introduced in <code>v0.4.0rc1</code> are explicitly highlighted with the <VersionBadge version="0.4.0rc1" status="prerelease" /> badge.

## Getting Started Path

Follow our structured onboarding guide to go from installation to a running production agent in minutes:

1. **[Installation](/en/docs/getting-started/installation):** Verify your Python environment (`>=3.10`), install core packages, and configure optional channel extras.
2. **[Quickstart](/en/docs/getting-started/quickstart):** Build your first agent in under 5 minutes, invoke custom tools with `@tool`, and explore asynchronous execution.
3. **[Core Concepts](/en/docs/getting-started/core-concepts):** Learn the foundational architecture: `Agent`, `Runner`, `Engines`, `Tools`, `Memory`, and `Handoffs`.
