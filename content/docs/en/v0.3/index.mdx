Welcome to the historical `v0.3` documentation for **chatflow-agent**, a lightweight, async-first Python framework engineered for building modular conversational agents and multi-agent swarms with native, type-safe handoffs.

Created and led by **Gustavo Baranda**, `chatflow-agent` focuses on a compact Python API, per-session async turn serialization for in-memory sessions, persistent SQLite sessions, and multi-channel connectivity.

---

## Architecture Highlights (`v0.3.4`)

<Cards>
  <Card title="Multiple Provider Engines">
    Uses `google-genai` for Gemini in `v0.3.4` and dedicated HTTP clients for Anthropic and OpenAI-compatible providers. REST-only Gemini (`httpx`) was introduced in `v0.4.0`.
  </Card>
  <Card title="Native Multi-Agent Handoffs">
    Declare collaborative swarms. Agents delegate tasks dynamically using synthesized `transfer_to_*` tools, with transfers per turn capped by `max_handoffs_per_turn`.
  </Card>
  <Card title="Session Memory">
    Persists conversations with in-memory or SQLite stores. For ordinary exceptions, `v0.3.4` restores conversation history length; it does not promise full-state or cancellation rollback. Dedicated SQLite worker thread-pool offloading was introduced in `v0.4.0`.
  </Card>
  <Card title="Multi-Channel Readiness">
    Deploy your agents seamlessly to terminal REPLs, Telegram bots, or WhatsApp Business Cloud API with HMAC SHA-256 signature verification.
  </Card>
</Cards>

## Release & Versioning Strategy

`chatflow-agent` strictly adheres to Semantic Versioning (SemVer). The documentation maintains two stable tracks:

* <VersionBadge version="0.4.0" status="stable" /> **Latest Stable Release (Default):** Recommended for all new production deployments. Includes direct `httpx` Gemini transport, default runtime tool argument validation, and full transactional turn rollbacks.
* <VersionBadge version="0.3.4" status="stable" /> **Previous Stable Release (Historical Track):** Documented in `/docs/v0.3` for teams maintaining existing `0.3.x` deployments.

```bash
# Install the v0.3.4 release documented on this track
pip install "chatflow-agent==0.3.4"

# Or install the latest stable release (v0.4.0 — recommended for new projects)
pip install chatflow-agent
```
