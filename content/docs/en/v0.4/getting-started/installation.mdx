`chatflow-agent` is distributed on [PyPI](https://pypi.org/project/chatflow-agent/) with a minimal core footprint. In **`v0.4.0`**, the core package depends only on **`pydantic>=2.6.0`** and **`httpx>=0.27.0,<1.0`** (`google-genai` was removed in `v0.4.0` because `GeminiEngine` now communicates directly with the Gemini REST API over `httpx.AsyncClient`). Channel integrations (`telegram`, `whatsapp`, `webhook`) are packaged as optional extras so production containers stay lean.

## System Requirements

* **Python:** `>= 3.10` (tested across Python 3.10, 3.11, 3.12, and 3.13)
* **Operating Systems:** Linux, macOS, and Windows
* **Core Dependencies (Installed Automatically):**
  * `pydantic >= 2.6.0` (Data validation, runtime tool argument validation, and JSON Schema generation)
  * `httpx >= 0.27.0, < 1.0` (Async HTTP transport for OpenAI, Gemini, Anthropic, Ollama, and WhatsApp engines)

## Installing the Package

<Steps>
  <Step>
    ### Create an Isolated Virtual Environment

    Always install `chatflow-agent` inside a dedicated virtual environment:

    <Tabs items={['venv (Standard)', 'uv']}>
      <Tab value="venv (Standard)">
```bash
python -m venv .venv

# Linux / macOS
source .venv/bin/activate

# Windows (PowerShell)
.venv\Scripts\Activate.ps1
```
      </Tab>
      <Tab value="uv">
```bash
uv venv
source .venv/bin/activate
```
      </Tab>
    </Tabs>
  </Step>

  <Step>
    ### Install `chatflow-agent` v0.4.0

    Choose the installation command matching your deployment needs:

    <Tabs items={['Core SDK (0.4.0)', 'Telegram Extra', 'WhatsApp Extra', 'Webhook Extra', 'All Extras']}>
      <Tab value="Core SDK (0.4.0)">
```bash
pip install chatflow-agent==0.4.0
```
      </Tab>
      <Tab value="Telegram Extra">
```bash
pip install "chatflow-agent[telegram]==0.4.0"
```
      </Tab>
      <Tab value="WhatsApp Extra">
```bash
pip install "chatflow-agent[whatsapp]==0.4.0"
```
      </Tab>
      <Tab value="Webhook Extra">
```bash
pip install "chatflow-agent[webhook]==0.4.0"
```
      </Tab>
      <Tab value="All Extras">
```bash
pip install "chatflow-agent[all]==0.4.0"
```
      </Tab>
    </Tabs>
  </Step>

    Run a quick sanity check to verify the installed package version and core imports:

  </Step>

## Optional Dependency Extras Matrix

The table below lists every optional extra defined in `pyproject.toml` for `v0.4.0` and when to install it:

| Extra Name | Install Command | Included Packages | Required By |
| :--- | :--- | :--- | :--- |
| *(Core)* | `pip install chatflow-agent==0.4.0` | `pydantic>=2.6.0`, `httpx>=0.27.0,<1.0` | `Agent`, `Runner`, `OpenAIEngine`, `GeminiEngine`, `AnthropicEngine`, `SessionStore`, `SQLiteSessionStore`, `CLIChannel` |
| `telegram` | `pip install "chatflow-agent[telegram]==0.4.0"` | `python-telegram-bot>=20.0` | `TelegramChannel` |
| `whatsapp` | `pip install "chatflow-agent[whatsapp]==0.4.0"` | `fastapi>=0.100.0`, `uvicorn>=0.23.0` | `WhatsAppChannel` |
| `webhook` | `pip install "chatflow-agent[webhook]==0.4.0"` | `fastapi>=0.100.0`, `uvicorn>=0.23.0`, `pydantic>=2.6.0` | Custom FastAPI webhook servers (`examples/webhook_bot.py`) |
| `all` | `pip install "chatflow-agent[all]==0.4.0"` | `python-telegram-bot>=20.0`, `fastapi>=0.100.0`, `uvicorn>=0.23.0` | Full multi-channel deployments |
| `dev` | `pip install "chatflow-agent[dev]==0.4.0"` | `pytest>=8.0.0`, `pytest-asyncio>=0.23.0`, `ruff>=0.3.0`, `mypy>=1.9.0` | Contributing and running the test suite |

<Callout type="info" title="Lazy Channel Imports & DependencyError">
If you attempt to instantiate `TelegramChannel` or `WhatsAppChannel` without installing its corresponding extra, `chatflow-agent` raises a descriptive `DependencyError` with the exact `pip install` command needed.
</Callout>

## Configuring Provider API Keys

`chatflow-agent` automatically resolves provider credentials from standard environment variables when `api_key` is not passed explicitly to an `Agent` or engine constructor:

| Provider | Environment Variable | Default Model Example | Engine Class |
| :--- | :--- | :--- | :--- |
| **Google Gemini** | `GOOGLE_API_KEY` or `GEMINI_API_KEY` | `gemini-2.5-flash` | `GeminiEngine` |
| **OpenAI** | `OPENAI_API_KEY` | `gpt-4o`, `gpt-4o-mini` | `OpenAIEngine` |
| **Anthropic** | `ANTHROPIC_API_KEY` | `claude-3-5-sonnet-latest` | `AnthropicEngine` |
| **DeepSeek** | `DEEPSEEK_API_KEY` | `deepseek-chat` | `OpenAIEngine(provider="deepseek")` |
| **Groq** | `GROQ_API_KEY` | `llama-3.3-70b-versatile` | `OpenAIEngine(provider="groq")` |
| **xAI Grok** | `XAI_API_KEY` or `GROK_API_KEY` | `grok-2-latest` | `OpenAIEngine(provider="grok")` |
| **Ollama (Local)** | `OLLAMA_API_KEY` *(optional; defaults to `"ollama"`)* | `llama3.2`, `qwen2.5` | `OpenAIEngine(provider="ollama")` |

Export the variables in your shell or load them via your process manager before starting your application:

```bash
export OPENAI_API_KEY="sk-..."
export GOOGLE_API_KEY="AIza..."
export ANTHROPIC_API_KEY="sk-ant-..."
```
