This guide walks you through creating a conversational agent equipped with a custom Python tool, executing multi-turn conversations through a `Runner`, and persisting session state to SQLite.

## 1. Minimal Agent in 10 Lines

When you create an `Agent` and pass it to a `Runner`, `chatflow-agent` automatically selects the right engine from the model name (`gpt-*`, `o1*`, `o3*` → `OpenAIEngine`, `claude-*` → `AnthropicEngine`, `gemini-*` → `GeminiEngine`):

```python
from chatflow_agent import Agent, Runner

assistant = Agent(
    name="Assistant",
    instructions="You are a concise, helpful technical assistant.",
    model="gpt-4o",
)

runner = Runner(starting_agent=assistant)

if __name__ == "__main__":
    response = runner.run(
        session_id="user-session-1",
        user_message="Explain Python asyncio in two sentences.",
    )
    print(f"[{response.active_agent_name}]: {response.content}")
```

## 2. Adding Custom Tools (`@tool`)

Agents become far more useful when they can invoke deterministic Python functions. Decorate any sync or async function with `@tool`—`chatflow-agent` inspects its type annotations and docstring to build an OpenAI-compatible JSON Schema automatically and validates model-supplied arguments at runtime with Pydantic (`validate_args=True` by default):

```python
# [executable]
from chatflow_agent import Agent, Runner, tool

@tool(name="calculate_discount", description="Calculate final price and savings after a percentage discount.")
def calculate_discount(price: float, discount_percent: float) -> str:
    savings = price * (discount_percent / 100.0)
    final_price = price - savings
    return f"Final price: ${final_price:.2f} (You save ${savings:.2f})"

sales_agent = Agent(
    name="SalesAssistant",
    instructions=(
        "You help customers with pricing questions. "
        "Always use the calculate_discount tool for math calculations."
    ),
    model="gpt-4o",
    tools=[calculate_discount],
)

runner = Runner(starting_agent=sales_agent)

if __name__ == "__main__" and False:  # Set API key to execute live turn
    result = runner.run(
        session_id="cart-session-42",
        user_message="How much is a $240 jacket with a 15% discount?",
    )
    print("Content:", result.content)
    print("Tools executed:", result.tool_calls_executed)
```

<Callout type="info" title="Inspecting Executed Tools">
Every `AgentResponse` returned by `runner.run()` or `await runner.run_async()` includes `response.tool_calls_executed` (a `list[str]` of tool names invoked during the turn), `response.active_agent_name`, and `response.handoff` (an `AgentHandoff` record if control transferred to another agent).
</Callout>

## 3. Asynchronous Execution & Persistent SQLite Memory

For web servers (FastAPI), Telegram bots, or WhatsApp webhooks, use `await runner.run_async()` combined with `SQLiteSessionStore`. In `v0.4.0`, `Runner` supports the `async with runner:` context manager (which automatically closes the runner's pooled Gemini HTTP client on exit) and `turn_timeout`:

```python
# [min-version: 0.4.0]
import asyncio
from chatflow_agent import Agent, Runner, SQLiteSessionStore

async def main() -> None:
    # Persist conversation history and metadata in SQLite (or ":memory:")
    store = SQLiteSessionStore(
        db_path=":memory:",
        default_max_turns=40,
    )

    tutor = Agent(
        name="PythonTutor",
        instructions="You are a friendly Python tutor. Remember the student's name and goals.",
        model="gemini-2.5-flash",
    )

    runner = Runner(
        starting_agent=tutor,
        session_store=store,
    )

    async with runner:
        # Turn 1: Introduce context
        r1 = await runner.run_async(
            session_id="student-ada",
            user_message="Hi! My name is Ada and I am learning async generators.",
            turn_timeout=30.0,
        )
        print("Turn 1:", r1.content)

        # Turn 2: Context is automatically recalled from SQLiteSessionStore
        r2 = await runner.run_async(
            session_id="student-ada",
            user_message="What was my name and what topic am I studying?",
            turn_timeout=30.0,
        )
        print("Turn 2:", r2.content)

if __name__ == "__main__":
    asyncio.run(main())
```

## 4. Testing Interactively in the Terminal (`CLIChannel`)

You can test any `Runner` interactively from your terminal without writing a loop by attaching `CLIChannel`:

```python
from chatflow_agent import Agent, CLIChannel, Runner

agent = Agent(
    name="LocalHelper",
    instructions="You are a helpful CLI assistant.",
    model="gemini-2.5-flash",
)

runner = Runner(starting_agent=agent)
cli = CLIChannel(session_id="local-dev-session", prompt_prefix="\nYou: ")
cli.attach(runner)

if __name__ == "__main__":
    # Type messages in the console; type '/reset' to clear history or 'exit' to quit
    cli.run()
```
