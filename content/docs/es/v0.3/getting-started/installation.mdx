## Requisitos Previos

Antes de instalar `chatflow-agent`, asegúrate de que tu sistema cumpla con los requisitos mínimos de Python:

* **Versión de Python:** Python `>=3.10` (probado en 3.10, 3.11, 3.12 y 3.13).
* **Gestor de Paquetes:** `pip`, `uv` o `poetry`.
* **Sistemas Operativos:** la CI del SDK se ejecuta en Linux (Ubuntu) y Windows. El paquete es Python puro, por lo que se espera que funcione en macOS y arm64, pero estas plataformas no forman parte de la matriz de CI.

Verifica la versión local de Python en tu terminal:

```bash
python --version
# La salida debe ser Python 3.10.x o superior
```

## Instalación del Paquete Principal

`chatflow-agent` mantiene reducidas sus dependencias principales: en v0.3.4 son `google-genai` (usada por `GeminiEngine`), `pydantic` y `httpx`. Puedes elegir entre la versión estable o la candidata de pre-lanzamiento:

<Tabs items={['pip', 'uv', 'poetry']}>
  <Tab value="pip">
```bash
# Instalar la versión estable actual (v0.3.4 - recomendada para producción)
pip install chatflow-agent

# O instalar la versión candidata de pre-lanzamiento (v0.4.0rc1, la única versión 0.4 publicada)
pip install "chatflow-agent==0.4.0rc1"
```
  </Tab>
  <Tab value="uv">
```bash
# Instalar la versión estable actual con uv
uv add chatflow-agent

# O instalar la versión candidata de pre-lanzamiento
uv add "chatflow-agent==0.4.0rc1"
```
  </Tab>
  <Tab value="poetry">
```bash
# Instalar la versión estable actual con poetry
poetry add chatflow-agent

# O instalar la versión candidata de pre-lanzamiento
poetry add chatflow-agent@0.4.0rc1
```
  </Tab>
</Tabs>

<Callout type="info" title="Dependencias Principales">
En **v0.3.4**, las dependencias principales son `google-genai>=0.1.1`, `pydantic>=2.6.0` y `httpx>=0.27.0`; `google-genai` se instala automáticamente. En la prerelease **v0.4.0rc1**, `google-genai` deja de ser una dependencia: los motores de Gemini, Anthropic y los compatibles con OpenAI se comunican mediante REST a través de `httpx`. La persistencia con SQLite utiliza la biblioteca integrada `sqlite3` de Python sin requerir controladores de bases de datos de terceros.
</Callout>

## Extras Opcionales de Canales

`chatflow-agent` declara dependencias opcionales en `pyproject.toml` para mantener el núcleo compacto. Instala únicamente las funciones que tu despliegue requiera:

| Nombre del Extra | Descripción | Dependencias Clave Agregadas | Comando |
| :--- | :--- | :--- | :--- |
| `[telegram]` | Integración con bots de Telegram mediante long polling (`TelegramChannel`) | `python-telegram-bot>=21.0` | `pip install "chatflow-agent[telegram]"` |
| `[whatsapp]` | Servidor de webhooks para Meta WhatsApp Cloud API (`WhatsAppChannel`) | `fastapi>=0.110.0`, `uvicorn>=0.29.0` | `pip install "chatflow-agent[whatsapp]"` |
| `[webhook]` | Instala FastAPI y Uvicorn para construir tu propio endpoint HTTP. No existe un canal de webhook genérico integrado; consulta la [guía de Webhooks Personalizados](/es/docs/v0.3/integrations/webhook) | `fastapi>=0.110.0`, `uvicorn>=0.29.0` | `pip install "chatflow-agent[webhook]"` |
| `[all]` | Instala todas las dependencias de canales simultáneamente | `telegram`, `whatsapp`, `webhook` | `pip install "chatflow-agent[all]"` |
| `[dev]` | Herramientas para ejecutar suites de pruebas unitarias y de integración | `pytest>=8.0.0`, `pytest-asyncio`, `ruff`, `mypy` | `pip install "chatflow-agent[dev]"` |

## Verificación

Confirma que `chatflow-agent` esté correctamente instalado consultando su versión en Python:

```bash
python -c "import chatflow_agent; print(chatflow_agent.__version__)"
```

Salida esperada:
```text
0.3.4
```
*(o `0.4.0rc1` si se instaló con el indicador de pre-lanzamiento)*.

## Configuración de Claves de API de Proveedores

Para interactuar con modelos LLM, exporta la clave de API del proveedor seleccionado como variable de entorno en tu terminal o archivo `.env`. Cada proveedor lee su propia variable, y solo cuando la solicitud va al endpoint oficial de ese proveedor; `OPENAI_API_KEY` nunca se envía a otro proveedor o host:

```bash
# OpenAI
export OPENAI_API_KEY="sk-..."

# xAI Grok (provider="grok" o provider="xai")
export XAI_API_KEY="xai-..."

# DeepSeek y Groq
export DEEPSEEK_API_KEY="sk-..."
export GROQ_API_KEY="gsk_..."

# Modelos Claude de Anthropic
export ANTHROPIC_API_KEY="sk-ant-..."

# Modelos Gemini de Google
export GEMINI_API_KEY="AIzaSy..."

# Un servidor local de Ollama no necesita clave. OLLAMA_API_KEY solo se usa si la defines.
```

En Windows PowerShell:
```powershell
$env:OPENAI_API_KEY="sk-..."
$env:ANTHROPIC_API_KEY="sk-ant-..."
$env:GEMINI_API_KEY="AIzaSy..."
```
