Bienvenido a la documentación oficial de **chatflow-agent**, un framework asíncrono y ligero en Python diseñado para construir agentes conversacionales modulares y enjambres multi-agente con transferencias (handoffs) nativas y fuertemente tipadas.

Creado y liderado por **Gustavo Baranda**, `chatflow-agent` se centra en una API compacta de Python, serialización asíncrona de turnos por sesión para sesiones en memoria, sesiones persistentes en SQLite y conectividad multicanal.

## Aspectos Destacados de la Arquitectura

<Cards>
  <Card title="Motores para Múltiples Proveedores">
    Usa `google-genai` para Gemini en la versión estable v0.3.4 y clientes HTTP dedicados para Anthropic y proveedores compatibles con OpenAI. Gemini sólo REST pertenece a v0.4.0rc1 prerelease.
  </Card>
  <Card title="Handoffs Multi-Agente Nativos">
    Declara enjambres colaborativos. Los agentes delegan tareas dinámicamente mediante herramientas sintetizadas `transfer_to_*`, con las transferencias por turno limitadas por `max_handoffs_per_turn`.
  </Card>
  <Card title="Memoria de Sesión">
    Persiste conversaciones en memoria o SQLite. Ante excepciones ordinarias, v0.3.4 restaura la longitud del historial; no garantiza rollback de todo el estado ni ante cancelación. El pool de threads para SQLite pertenece a v0.4.0rc1 prerelease.
  </Card>
  <Card title="Preparado para Múltiples Canales">
    Despliega tus agentes sin complicaciones en terminales REPL, bots de Telegram o en la API de WhatsApp Business Cloud con verificación criptográfica HMAC SHA-256.
  </Card>
</Cards>

## Estrategia de Lanzamientos y Versionado

`chatflow-agent` sigue estrictamente el Versionado Semántico (SemVer). La documentación está organizada por versiones:

* <VersionBadge version="0.3.4" status="stable" /> **Versión Estable Actual (Predeterminada):** Recomendada para todos los despliegues en producción. Publicada en PyPI el 23 de octubre de 2026.
* <VersionBadge version="0.4.0rc1" status="prerelease" /> **Versión Candidata 1 (Pre-lanzamiento):** Disponible en PyPI para evaluar mejoras arquitectónicas futuras, incluyendo la ejecución nativa de Gemini vía REST y validación de nombres duplicados en enjambres.

```bash
# Instalar la versión estable (predeterminada)
pip install chatflow-agent

# Instalar la versión candidata de pre-lanzamiento
pip install "chatflow-agent==0.4.0rc1"
```
