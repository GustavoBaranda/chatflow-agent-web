Bienvenido a la documentación histórica `v0.3` de **chatflow-agent**, un framework asíncrono y ligero en Python diseñado para construir agentes conversacionales modulares y enjambres multi-agente con transferencias (*handoffs*) nativas y fuertemente tipadas.

Creado y liderado por **Gustavo Baranda**, `chatflow-agent` se centra en una API compacta de Python, serialización asíncrona de turnos por sesión para sesiones en memoria, sesiones persistentes en SQLite y conectividad multicanal.

## Aspectos Destacados de la Arquitectura (`v0.3.4`)

<Cards>
  <Card title="Motores para Múltiples Proveedores">
    Usa `google-genai` para Gemini en `v0.3.4` y clientes HTTP dedicados para Anthropic y proveedores compatibles con OpenAI. Gemini sólo REST (`httpx`) se introdujo en `v0.4.0`.
  </Card>
  <Card title="Handoffs Multi-Agente Nativos">
    Declara enjambres colaborativos. Los agentes delegan tareas dinámicamente mediante herramientas sintetizadas `transfer_to_*`, con las transferencias por turno limitadas por `max_handoffs_per_turn`.
  </Card>
  <Card title="Memoria de Sesión">
    Persiste conversaciones en memoria o SQLite. Ante excepciones ordinarias, `v0.3.4` restaura la longitud del historial; no garantiza rollback de todo el estado ni ante cancelación. El pool dedicado de threads para SQLite se introdujo en `v0.4.0`.
  </Card>
  <Card title="Preparado para Múltiples Canales">
    Despliega tus agentes sin complicaciones en terminales REPL, bots de Telegram o en la API de WhatsApp Business Cloud con verificación criptográfica HMAC SHA-256.
  </Card>
</Cards>

## Estrategia de Lanzamientos y Versionado

`chatflow-agent` sigue estrictamente el Versionado Semántico (SemVer). La documentación mantiene dos líneas estables:

* <VersionBadge version="0.4.0" status="stable" /> **Última Versión Estable (Predeterminada):** Recomendada para todos los despliegues nuevos en producción. Incluye transporte REST directo para Gemini con `httpx`, validación en tiempo de ejecución de argumentos de herramientas y reversión transaccional completa de turnos.
* <VersionBadge version="0.3.4" status="stable" /> **Versión Estable Anterior (Línea Histórica):** Documentada en `/docs/v0.3` para equipos que mantienen despliegues existentes en `0.3.x`.

```bash

pip install "chatflow-agent==0.3.4"

# O instalar la última versión estable (v0.4.0 — recomendada para nuevos proyectos)
pip install chatflow-agent
```
