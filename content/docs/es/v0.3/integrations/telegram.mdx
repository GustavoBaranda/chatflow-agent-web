`TelegramChannel` conecta enjambres de `chatflow-agent` con bots de Telegram. Impulsado por la biblioteca asíncrona `python-telegram-bot`, gestiona polling, aislamiento de sesiones por ID de chat, fragmentación automática de mensajes y políticas de seguridad para chats grupales.

## Instalación

Instala `chatflow-agent` con el extra `telegram` para incluir las dependencias requeridas (`python-telegram-bot>=21.0`):

```bash
pip install "chatflow-agent[telegram]"
```

## Configuración Rápida del Bot

<Steps>
  <Step>
    ### Crear un Bot vía BotFather

    1. Abre Telegram y busca [@BotFather](https://t.me/BotFather).
    2. Envía `/newbot` y sigue las indicaciones para elegir un nombre público y un nombre de usuario.
    3. Copia el token de API HTTP del bot generado.
  </Step>

  <Step>
    ### Implementar el Script del Canal

    Crea un script vinculando un `Runner` a `TelegramChannel`:

```python
import os
from chatflow_agent import Agent, Runner
from chatflow_agent.channels import TelegramChannel
from chatflow_agent.core.memory import SQLiteSessionStore

# Definir tu agente
support_agent = Agent(
    name="SupportBot",
    instructions="You are a helpful customer support representative.",
)

# Configurar almacenamiento persistente de sesiones
store = SQLiteSessionStore("telegram_sessions.db")
runner = Runner(starting_agent=support_agent, session_store=store)

# Inicializar canal de Telegram
telegram = TelegramChannel(
    token=os.environ.get("TELEGRAM_BOT_TOKEN", "your-bot-token"),
    start_message="Welcome! How can I assist you today?",
)

# Vincular runner y ejecutar bucle de polling
telegram.attach(runner)

if __name__ == "__main__":
    print("Starting Telegram bot polling...")
    telegram.run()
```
  </Step>
</Steps>

## Parámetros de Configuración del Canal

El constructor de `TelegramChannel` acepta las siguientes opciones:

| Parámetro | Tipo | Predeterminado | Descripción |
| :--- | :--- | :--- | :--- |
| `token` | `str` | *Obligatorio* | Token de la API de Telegram emitido por @BotFather. |
| `start_message` | `str` | `"Hello! I am your AI..."` | Mensaje de bienvenida enviado cuando un usuario ejecuta `/start`. |
| `fallback_message` | `str` | `"Disculpa, ocurrió un..."` | Mensaje enviado al usuario si la ejecución del modelo falla. |
| `allowed_updates` | `list[str] \| None` | `None` | Restringe tipos de actualizaciones (ej. `["message"]`). Por defecto admite todas. |

## Comandos Integrados y Seguridad en Chats Grupales

`TelegramChannel` incluye manejadores preconfigurados para comandos esenciales:

### Comando `/start`
Responde con `start_message` para dar la bienvenida a nuevos usuarios.

### Comando `/reset`
Limpia el historial de la sesión en `runner.session_store` para el ID de chat activo, permitiendo a los usuarios reiniciar su conversación limpiamente.

<Callout type="warn" title="Seguridad en Chats Grupales y Supergrupos">
En chats grupales y supergrupos, permitir que cualquier miembro borre la conversación podría afectar a otros usuarios. `TelegramChannel` aplica verificación de roles:
* **Creadores y Administradores:** Autorizados a ejecutar `/reset`.
* **Miembros Estándar:** Ejecución denegada con la respuesta: `"Only group admins can reset the conversation."`.
</Callout>

## Fragmentación de Mensajes Salientes (`split_message`)

Telegram impone un límite estricto de **4096 caracteres por mensaje de texto**. Cuando un agente genera análisis extensos, bloques de código o tablas, enviar el texto completo de forma directa hace que la API de Telegram responda con error HTTP 400.

`TelegramChannel` canaliza automáticamente las respuestas a través de `split_message`:

```python
# [min-version: 0.3.2]
# [executable]
from chatflow_agent.channels import split_message

long_text = "Detailed agent analysis..." * 200
chunks = split_message(long_text, max_len=4096)
# Divide progresivamente por \n\n, \n, puntos o espacios para preservar legibilidad
```

El canal entrega los fragmentos secuencialmente. `split_message` prioriza los límites de párrafo, línea, oración y, por último, palabra; cuando un fragmento no contiene ningún separador (por ejemplo, una URL muy larga), recurre a un corte forzado en `max_len`. Las longitudes se cuentan en caracteres de Python.

## Indicadores de Escritura y Experiencia de Usuario

Cuando llega un mensaje, `TelegramChannel` envía un único indicador `ChatAction.TYPING` antes de despachar el turno (los errores de esa llamada se ignoran). No se repite mientras el turno se ejecuta, por lo que en turnos largos el estado de escritura de Telegram puede desaparecer antes de que llegue la respuesta.

## Gestión del Bucle de Eventos

`run()` inicia el long polling y bloquea: controla el bucle de eventos por sí mismo mediante `run_polling()` de python-telegram-bot, y los argumentos con nombre se transmiten a esa función. Pasar `close_loop=False` mantiene abierto el bucle de eventos después de que `run()` retorne:

```python
telegram.run(drop_pending_updates=True, close_loop=False)
```

`close_loop=False` no hace que `run()` pueda usarse dentro de un bucle de eventos que ya está en ejecución, como el de una aplicación FastAPI. `TelegramChannel` no proporciona un método de inicio no bloqueante.
