Esta guía te acompaña para crear un agente conversacional equipado con una herramienta Python personalizada, ejecutar conversaciones multi-turno con `Runner` y persistir el estado de sesión en SQLite.

## 1. Agente Mínimo en 10 Líneas

Cuando creas un `Agent` y lo pasas a un `Runner`, `chatflow-agent` selecciona automáticamente el motor adecuado a partir del nombre del modelo (`gpt-*`, `o1*`, `o3*` → `OpenAIEngine`, `claude-*` → `AnthropicEngine`, `gemini-*` → `GeminiEngine`):

```python
from chatflow_agent import Agent, Runner

assistant = Agent(
    name="Assistant",
    instructions="You are a concise, helpful technical assistant.",
    model="gpt-4o",
)

runner = Runner(starting_agent=assistant)

if __name__ == "__main__":
    response = runner.run(
        session_id="user-session-1",
        user_message="Explain Python asyncio in two sentences.",
    )
    print(f"[{response.active_agent_name}]: {response.content}")
```

## 2. Agregar Herramientas Personalizadas (`@tool`)

Los agentes resultan mucho más útiles cuando pueden invocar funciones Python deterministas. Decora cualquier función síncrona o asíncrona con `@tool`: `chatflow-agent` inspecciona sus anotaciones de tipo y docstring para construir un JSON Schema compatible con OpenAI y valida los argumentos del modelo en tiempo de ejecución con Pydantic (`validate_args=True` por defecto):

```python
# [executable]
from chatflow_agent import Agent, Runner, tool

@tool(name="calculate_discount", description="Calculate final price and savings after a percentage discount.")
def calculate_discount(price: float, discount_percent: float) -> str:
    savings = price * (discount_percent / 100.0)
    final_price = price - savings
    return f"Final price: ${final_price:.2f} (You save ${savings:.2f})"

sales_agent = Agent(
    name="SalesAssistant",
    instructions=(
        "You help customers with pricing questions. "
        "Always use the calculate_discount tool for math calculations."
    ),
    model="gpt-4o",
    tools=[calculate_discount],
)

runner = Runner(starting_agent=sales_agent)

if __name__ == "__main__" and False:  # Configura tu API key para ejecutar un turno real
    result = runner.run(
        session_id="cart-session-42",
        user_message="How much is a $240 jacket with a 15% discount?",
    )
    print("Content:", result.content)
    print("Tools executed:", result.tool_calls_executed)
```

<Callout type="info" title="Inspección de Herramientas Ejecutadas">
Cada `AgentResponse` retornado por `runner.run()` o `await runner.run_async()` incluye `response.tool_calls_executed` (un `list[str]` con los nombres de las herramientas invocadas en el turno), `response.active_agent_name` y `response.handoff` (`Handoff | None`, poblado si el control fue transferido a otro agente).
</Callout>

## 3. Ejecución Asíncrona y Memoria Persistente en SQLite

Para servidores web (FastAPI), bots de Telegram o webhooks de WhatsApp, utiliza `await runner.run_async()` junto con `SQLiteSessionStore`. En `v0.4.0`, `Runner` soporta el gestor de contexto `async with runner:` (que cierra automáticamente el cliente HTTP compartido de Gemini al salir) y `turn_timeout`:

```python
# [min-version: 0.4.0]
import asyncio
from chatflow_agent import Agent, Runner, SQLiteSessionStore

async def main() -> None:
    # Persistir historial y metadatos en SQLite (o ":memory:")
    store = SQLiteSessionStore(
        db_path=":memory:",
        default_max_turns=40,
    )

    tutor = Agent(
        name="PythonTutor",
        instructions="You are a friendly Python tutor. Remember the student's name and goals.",
        model="gemini-2.5-flash",
    )

    runner = Runner(
        starting_agent=tutor,
        session_store=store,
    )

    async with runner:
        # Turno 1: Introducir contexto
        r1 = await runner.run_async(
            session_id="student-ada",
            user_message="Hi! My name is Ada and I am learning async generators.",
            turn_timeout=30.0,
        )
        print("Turn 1:", r1.content)

        # Turno 2: El contexto se recupera automáticamente desde SQLiteSessionStore
        r2 = await runner.run_async(
            session_id="student-ada",
            user_message="What was my name and what topic am I studying?",
            turn_timeout=30.0,
        )
        print("Turn 2:", r2.content)

if __name__ == "__main__":
    asyncio.run(main())
```

## 4. Pruebas Interactivas en Terminal (`CLIChannel`)

Puedes probar cualquier `Runner` de forma interactiva desde la terminal sin escribir un bucle manual conectando `CLIChannel`:

```python
from chatflow_agent import Agent, CLIChannel, Runner

agent = Agent(
    name="LocalHelper",
    instructions="You are a helpful CLI assistant.",
    model="gemini-2.5-flash",
)

runner = Runner(starting_agent=agent)
cli = CLIChannel(session_id="local-dev-session", prompt_prefix="\nYou: ")
cli.attach(runner)

if __name__ == "__main__":
    # Escribe mensajes en consola; usa '/reset' para limpiar el historial o 'exit' para salir
    cli.run()
```
