Bienvenido a la documentación oficial de **chatflow-agent**, un framework liviano y reactivo en Python diseñado para construir agentes conversacionales de IA robustos y con gestión de estado.

## Capacidades Principales

- **Máquina de Estados Reactiva**: Gestiona diálogos complejos de múltiples turnos con transiciones de estado limpias.
- **Validación de Esquemas**: Manejo fuertemente tipado de cargas útiles y acciones mediante tipado estándar.
- **Arquitectura Extensible**: Integra herramientas personalizadas, proveedores de LLM y almacenamiento de memoria con facilidad.
- **Listo para Producción**: Diseñado para despliegues de baja latencia en la nube y en entornos locales.

## Instalación Rápida

```bash
pip install chatflow-agent
```

> **Nota**: La versión estable actual es `v0.3.4`. La versión candidata `v0.4.0rc1` se encuentra disponible para evaluar funciones preliminares.
