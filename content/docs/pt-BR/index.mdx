# Documentação do chatflow-agent

Bem-vindo à documentação oficial do **chatflow-agent**, um framework leve e reativo em Python desenvolvido para criar agentes de IA conversacionais robustos e com controle de estado.

## Recursos Principais

- **Máquina de Estados Reativa**: Gerencie diálogos complexos de múltiplos turnos com transições de estado limpas.
- **Validação Estrita de Esquemas**: Tratamento fortemente tipado de cargas úteis e ações com tipagem padrão.
- **Arquitetura Plugável**: Integre ferramentas customizadas, provedores de LLM e armazenamento de memória com facilidade.
- **Pronto para Produção**: Projetado para implementações de baixa latência em nuvem e borda.

## Instalação Rápida

```bash
pip install chatflow-agent
```

> **Nota**: O lançamento estável atual é `v0.3.4`. A versão candidata `v0.4.0rc1` está disponível para testes de novos recursos.
