Bem-vindo à documentação oficial do **chatflow-agent**, um framework assíncrono e leve em Python projetado para construir agentes conversacionais modulares e enxames multiagente com transferências (*handoffs*) nativas e fortemente tipadas.

Criado e liderado por **Gustavo Baranda** junto a uma comunidade internacional de código aberto, o `chatflow-agent` foi concebido para eliminar o excesso de complexidade de frameworks monolíticos e a dependência de fornecedores (*vendor lock-in*), oferecendo concorrência de nível empresarial, memória resiliente e conectividade multicanal.

---

## Destaques da Arquitetura

<Cards>
  <Card title="Zero Bloqueio de SDKs (Vendor Lock-In)">
    Conecta-se a modelos LLM através de REST HTTP assíncrono puro usando `httpx`. Sem necessidade de SDKs pesados ou dependências desnecessárias em tempo de execução.
  </Card>
  <Card title="Handoffs Multiagente Nativos">
    Declare enxames colaborativos. Os agentes delegam tarefas dinamicamente usando ferramentas sintetizadas `transfer_to_*` com prevenção automática de ciclos.
  </Card>
  <Card title="Memória Transacional e Resiliente">
    Cada turno realiza uma captura atômica de estado. Em caso de erro ou estouro de tempo limite, o estado é revertido automaticamente. As operações SQLite rodam em pools de threads dedicados.
  </Card>
  <Card title="Pronto para Múltiplos Canais">
    Implante seus agentes facilmente em terminais REPL, bots do Telegram ou na API do WhatsApp Business Cloud com verificação de assinatura HMAC SHA-256.
  </Card>
</Cards>

## Estratégia de Lançamentos e Versionamento

O `chatflow-agent` segue rigorosamente o Versionamento Semântico (SemVer). A documentação é organizada por faixas de versão:

* <VersionBadge version="0.3.4" status="stable" /> **Versão Estável Atual (Padrão):** Recomendada para todas as implantações em produção. Publicada no PyPI em 23 de outubro de 2026.
* <VersionBadge version="0.4.0rc1" status="prerelease" /> **Versão Candidata 1 (Pré-lançamento):** Disponível no PyPI para testes de novos aprimoramentos arquiteturais, incluindo execução nativa do Gemini via REST e validação de nomes duplicados em enxames.

```bash
# Instalar a versão estável atual (padrão)
pip install chatflow-agent

# Instalar a versão candidata de pré-lançamento
pip install "chatflow-agent==0.4.0rc1"
```
