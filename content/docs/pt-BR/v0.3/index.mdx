Bem-vindo à documentação histórica `v0.3` do **chatflow-agent**, um framework assíncrono e leve em Python projetado para construir agentes conversacionais modulares e enxames multiagente com transferências (*handoffs*) nativas e fortemente tipadas.

Criado e liderado por **Gustavo Baranda**, o `chatflow-agent` concentra-se em uma API Python compacta, serialização assíncrona de turnos por sessão para sessões em memória, sessões persistentes em SQLite e conectividade multicanal.

## Destaques da Arquitetura (`v0.3.4`)

<Cards>
  <Card title="Motores para Vários Provedores">
    Usa `google-genai` para Gemini na `v0.3.4` e clientes HTTP dedicados para Anthropic e provedores compatíveis com OpenAI. Gemini somente por REST (`httpx`) foi introduzido na `v0.4.0`.
  </Card>
  <Card title="Handoffs Multiagente Nativos">
    Declare enxames colaborativos. Os agentes delegam tarefas dinamicamente usando ferramentas sintetizadas `transfer_to_*`, com as transferências por turno limitadas por `max_handoffs_per_turn`.
  </Card>
  <Card title="Memória de Sessão">
    Persiste conversas em memória ou SQLite. Para exceções comuns, a `v0.3.4` restaura o tamanho do histórico; não garante rollback de todo o estado nem em cancelamentos. O pool dedicado de threads para SQLite foi introduzido na `v0.4.0`.
  </Card>
  <Card title="Pronto para Múltiplos Canais">
    Implante seus agentes facilmente em terminais REPL, bots do Telegram ou na API do WhatsApp Business Cloud com verificação de assinatura HMAC SHA-256.
  </Card>
</Cards>

## Estratégia de Lançamentos e Versionamento

O `chatflow-agent` segue rigorosamente o Versionamento Semântico (SemVer). A documentação mantém duas linhas estáveis:

* <VersionBadge version="0.4.0" status="stable" /> **Última Versão Estável (Padrão):** Recomendada para todas as novas implantações em produção. Inclui transporte REST direto para Gemini via `httpx`, validação de argumentos de ferramentas em tempo de execução e reversão transacional completa de turnos.
* <VersionBadge version="0.3.4" status="stable" /> **Versão Estável Anterior (Linha Histórica):** Documentada em `/docs/v0.3` para equipes que mantêm implantações existentes na série `0.3.x`.

```bash
# Instalar a versão v0.3.4 documentada nesta linha
pip install "chatflow-agent==0.3.4"

# Ou instalar a última versão estável (v0.4.0 — recomendada para novos projetos)
pip install chatflow-agent
```
