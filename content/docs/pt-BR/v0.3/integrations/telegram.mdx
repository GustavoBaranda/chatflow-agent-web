O `TelegramChannel` conecta enxames do `chatflow-agent` a bots do Telegram. Desenvolvido sobre a biblioteca assíncrona `python-telegram-bot`, ele gerencia polling, isolamento de sessões por ID de chat, fragmentação automática de mensagens e políticas de segurança para chats em grupo.

## Instalação

Instale o `chatflow-agent` com o extra `telegram` para incluir as dependências necessárias (`python-telegram-bot>=21.0`):

```bash
pip install "chatflow-agent[telegram]"
```

## Configuração Rápida do Bot

<Steps>
  <Step>
    ### Criar um Bot via BotFather

    1. Abra o Telegram e pesquise por [@BotFather](https://t.me/BotFather).
    2. Envie `/newbot` e siga as instruções para escolher um nome de exibição e nome de usuário.
    3. Copie o token de API HTTP gerado para o bot.
  </Step>

  <Step>
    ### Implementar o Script do Canal

    Crie um script vinculando um `Runner` ao `TelegramChannel`:

```python
import os
from chatflow_agent import Agent, Runner
from chatflow_agent.channels import TelegramChannel
from chatflow_agent.core.memory import SQLiteSessionStore

# Definir seu agente
support_agent = Agent(
    name="SupportBot",
    instructions="You are a helpful customer support representative.",
)

# Configurar armazenamento persistente de sessões
store = SQLiteSessionStore("telegram_sessions.db")
runner = Runner(starting_agent=support_agent, session_store=store)

# Inicializar canal do Telegram
telegram = TelegramChannel(
    token=os.environ.get("TELEGRAM_BOT_TOKEN", "your-bot-token"),
    start_message="Welcome! How can I assist you today?",
)

# Vincular runner e executar loop de polling
telegram.attach(runner)

if __name__ == "__main__":
    print("Starting Telegram bot polling...")
    telegram.run()
```
  </Step>
</Steps>

## Parâmetros de Configuração do Canal

O construtor do `TelegramChannel` aceita as seguintes opções:

| Parâmetro | Tipo | Padrão | Descrição |
| :--- | :--- | :--- | :--- |
| `token` | `str` | *Obrigatório* | Token da API do Bot do Telegram emitido pelo @BotFather. |
| `start_message` | `str` | `"Hello! I am your AI..."` | Mensagem de saudação enviada quando um usuário executa `/start`. |
| `fallback_message` | `str` | `"Disculpa, ocurrió un..."` | Mensagem voltada ao usuário enviada quando a execução do modelo falha. |
| `allowed_updates` | `list[str] \| None` | `None` | Restringe tipos de atualizações (ex.: `["message"]`). O padrão aceita todas. |

## Comandos Integrados e Segurança em Grupos

O `TelegramChannel` inclui manipuladores pré-configurados para comandos fundamentais:

### Comando `/start`
Responde com `start_message` para recepcionar novos usuários.

### Comando `/reset`
Limpa o histórico da sessão no `runner.session_store` para o ID de chat ativo, permitindo que os usuários reiniciem suas conversas de forma limpa.

<Callout type="warn" title="Segurança em Chats de Grupo e Supergrupos">
Em chats de grupo e supergrupos, permitir que qualquer participante apague a conversa pode prejudicar outros membros. O `TelegramChannel` aplica verificação de permissões:
* **Criadores e Administradores:** Autorizados a executar `/reset`.
* **Membros Padrão:** Execução recusada com a mensagem: `"Only group admins can reset the conversation."`.

## Fragmentação de Mensagens de Saída (`split_message`)

O Telegram impõe um limite rígido de **4096 caracteres por mensagem de texto**. Quando um agente gera análises extensas, blocos de código ou tabelas, o envio direto do texto completo faz com que a API do Telegram retorne erro HTTP 400.

O `TelegramChannel` canaliza respostas automaticamente por meio de `split_message`:

```python
# [min-version: 0.3.2]
# [executable]
from chatflow_agent.channels import split_message

long_text = "Detailed agent analysis..." * 200
chunks = split_message(long_text, max_len=4096)
# Divide progressivamente por \n\n, \n, pontos ou espaços para manter a legibilidade
```

O canal entrega os fragmentos em sequência. O `split_message` prefere limites de parágrafo, de linha, de frase e, por fim, de palavra; quando um fragmento não contém nenhum separador (por exemplo, uma URL muito longa), recorre a um corte rígido em `max_len`. Os comprimentos são contados em caracteres Python.

## Indicadores de Digitação e Experiência do Usuário

Quando uma mensagem chega, o `TelegramChannel` envia um único indicador `ChatAction.TYPING` antes de despachar o turno (erros dessa chamada são ignorados). Ele não é repetido enquanto o turno é executado, portanto, em turnos longos, o status de digitação do Telegram pode desaparecer antes que a resposta chegue.

## Gerenciamento do Loop de Eventos

O `run()` inicia o long polling e bloqueia: ele conduz o próprio loop de eventos por meio do `run_polling()` do python-telegram-bot, e os argumentos nomeados são repassados a ele. Passar `close_loop=False` mantém o loop de eventos aberto depois que `run()` retorna:

```python
telegram.run(drop_pending_updates=True, close_loop=False)
```

`close_loop=False` não torna o `run()` utilizável dentro de um loop de eventos que já está em execução, como o de uma aplicação FastAPI. O `TelegramChannel` não oferece um método de inicialização não bloqueante.
