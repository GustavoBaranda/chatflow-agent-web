## Pré-requisitos

Antes de instalar o `chatflow-agent`, certifique-se de que seu sistema atende aos requisitos mínimos de Python:

* **Versão do Python:** Python `>=3.10` (testado nas versões 3.10, 3.11, 3.12 e 3.13).
* **Gerenciador de Pacotes:** `pip`, `uv` ou `poetry`.
* **Sistemas Operacionais:** Linux, macOS e Windows (x86_64, arm64).

Verifique sua versão local do Python no terminal:

```bash
python --version
# A saída deve ser Python 3.10.x ou superior
```

---

## Instalando o Pacote Principal

O `chatflow-agent` disponibiliza um núcleo leve com zero dependências pesadas de provedores. Escolha entre a versão estável de produção ou a versão candidata de pré-lançamento:

<Tabs items={['pip', 'uv', 'poetry']}>
  <Tab value="pip">
```bash
# Instalar a versão estável atual (v0.3.4 - recomendada para produção)
pip install chatflow-agent

# Ou instalar a versão candidata de pré-lançamento (v0.4.0rc1+)
pip install --pre chatflow-agent
# ou: pip install "chatflow-agent==0.4.0rc1"
```
  </Tab>
  <Tab value="uv">
```bash
# Instalar a versão estável atual com uv
uv add chatflow-agent

# Ou instalar a versão candidata de pré-lançamento
uv add --prerelease=allow chatflow-agent
# ou: uv add "chatflow-agent==0.4.0rc1"
```
  </Tab>
  <Tab value="poetry">
```bash
# Instalar a versão estável atual com poetry
poetry add chatflow-agent

# Ou instalar a versão candidata de pré-lançamento
poetry add chatflow-agent@0.4.0rc1
```
  </Tab>
</Tabs>

<Callout type="info" title="Zero Bloqueio de SDKs (Vendor Lock-In) e Dependências Principais">
Na versão **v0.3.4**, as dependências principais limitam-se estritamente a `google-genai>=0.1.1`, `pydantic>=2.6.0` e `httpx>=0.27.0`. Na **v0.4.0rc1+**, `google-genai` não é mais necessário: toda a comunicação com Gemini e endpoints compatíveis com OpenAI é executada diretamente sobre REST assíncrono via `httpx`. A persistência SQLite utiliza a biblioteca nativa `sqlite3` do Python sem requerer drivers adicionais de banco de dados.
</Callout>

## Extras Opcionais de Canais

O `chatflow-agent` declara dependências opcionais no `pyproject.toml` para manter a base principal enxuta. Instale apenas os recursos necessários para a sua implantação:

| Nome do Extra | Descrição | Principais Dependências Adicionadas | Comando |
| :--- | :--- | :--- | :--- |
| `[telegram]` | Integração com bots do Telegram via polling ou webhooks | `python-telegram-bot>=21.0` | `pip install "chatflow-agent[telegram]"` |
| `[whatsapp]` | Webhooks da Meta WhatsApp Cloud API e listener de webhooks | `fastapi>=0.110.0`, `uvicorn>=0.29.0` | `pip install "chatflow-agent[whatsapp]"` |
| `[webhook]` | Servidor de webhooks HTTP genérico para integrações externas | `fastapi>=0.110.0`, `uvicorn>=0.29.0` | `pip install "chatflow-agent[webhook]"` |
| `[all]` | Instala todas as dependências de canais simultaneamente | `telegram`, `whatsapp`, `webhook` | `pip install "chatflow-agent[all]"` |
| `[dev]` | Ferramentas para executar suítes de testes unitários e de integração | `pytest>=8.0.0`, `pytest-asyncio`, `ruff`, `mypy` | `pip install "chatflow-agent[dev]"` |

## Verificação

Confirme se o `chatflow-agent` foi instalado corretamente verificando a versão no Python:

```bash
python -c "import chatflow_agent; print(chatflow_agent.__version__)"
```

Saída esperada:
```text
0.3.4
```
*(ou `0.4.0rc1` caso tenha instalado com a flag de pré-lançamento)*.

## Configuração de Chaves de API dos Provedores

Para interagir com LLMs, exporte a chave de API do provedor escolhido como variável de ambiente no seu terminal ou arquivo `.env`:

```bash
# Provedores OpenAI ou compatíveis com OpenAI (Groq, xAI, DeepSeek, Ollama)
export OPENAI_API_KEY="sk-..."

# Modelos Anthropic Claude
export ANTHROPIC_API_KEY="sk-ant-..."

# Modelos Google Gemini
export GEMINI_API_KEY="AIzaSy..."
```

No Windows PowerShell:
```powershell
$env:OPENAI_API_KEY="sk-..."
$env:ANTHROPIC_API_KEY="sk-ant-..."
$env:GEMINI_API_KEY="AIzaSy..."
```
