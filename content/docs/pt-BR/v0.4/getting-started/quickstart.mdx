Este guia mostra como criar um agente conversacional equipado com uma ferramenta Python personalizada, executar conversas multi-turno com o `Runner` e persistir o estado da sessão em SQLite.

## 1. Agente Mínimo em 10 Linhas

Ao criar um `Agent` e passá-lo a um `Runner`, o `chatflow-agent` seleciona automaticamente o motor adequado pelo nome do modelo (`gpt-*`, `o1*`, `o3*` → `OpenAIEngine`, `claude-*` → `AnthropicEngine`, `gemini-*` → `GeminiEngine`):

```python
from chatflow_agent import Agent, Runner

assistant = Agent(
    name="Assistant",
    instructions="You are a concise, helpful technical assistant.",
    model="gpt-4o",
)

runner = Runner(starting_agent=assistant)

if __name__ == "__main__":
    response = runner.run(
        session_id="user-session-1",
        user_message="Explain Python asyncio in two sentences.",
    )
    print(f"[{response.active_agent_name}]: {response.content}")
```

## 2. Adicionando Ferramentas Personalizadas (`@tool`)

Os agentes tornam-se muito mais úteis quando podem chamar funções Python determinísticas. Decore qualquer função síncrona ou assíncrona com `@tool` — o `chatflow-agent` inspeciona as anotações de tipo e docstring para gerar um JSON Schema compatível com OpenAI e valida os argumentos do modelo em tempo de execução com Pydantic (`validate_args=True` por padrão):

```python
# [executable]
from chatflow_agent import Agent, Runner, tool

@tool(name="calculate_discount", description="Calculate final price and savings after a percentage discount.")
def calculate_discount(price: float, discount_percent: float) -> str:
    savings = price * (discount_percent / 100.0)
    final_price = price - savings
    return f"Final price: ${final_price:.2f} (You save ${savings:.2f})"

sales_agent = Agent(
    name="SalesAssistant",
    instructions=(
        "You help customers with pricing questions. "
        "Always use the calculate_discount tool for math calculations."
    ),
    model="gpt-4o",
    tools=[calculate_discount],
)

runner = Runner(starting_agent=sales_agent)

if __name__ == "__main__" and False:  # Configure a API key para executar um turno real
    result = runner.run(
        session_id="cart-session-42",
        user_message="How much is a $240 jacket with a 15% discount?",
    )
    print("Content:", result.content)
    print("Tools executed:", result.tool_calls_executed)
```

<Callout type="info" title="Inspecionando Ferramentas Executadas">
Cada `AgentResponse` retornado por `runner.run()` ou `await runner.run_async()` inclui `response.tool_calls_executed` (uma `list[str]` com os nomes das ferramentas chamadas no turno), `response.active_agent_name` e `response.handoff` (um registro `AgentHandoff` se o controle foi transferido a outro agente).
</Callout>

## 3. Execução Assíncrona e Memória Persistente em SQLite

Para servidores web (FastAPI), bots do Telegram ou webhooks do WhatsApp, utilize `await runner.run_async()` combinado com `SQLiteSessionStore`. Na `v0.4.0`, o `Runner` suporta o gerenciador de contexto `async with runner:` (que fecha automaticamente o cliente HTTP compartilhado do Gemini ao sair) e `turn_timeout`:

```python
# [min-version: 0.4.0]
import asyncio
from chatflow_agent import Agent, Runner, SQLiteSessionStore

async def main() -> None:
    # Persistir histórico e metadados em SQLite (ou ":memory:")
    store = SQLiteSessionStore(
        db_path=":memory:",
        default_max_turns=40,
    )

    tutor = Agent(
        name="PythonTutor",
        instructions="You are a friendly Python tutor. Remember the student's name and goals.",
        model="gemini-2.5-flash",
    )

    runner = Runner(
        starting_agent=tutor,
        session_store=store,
    )

    async with runner:
        # Turno 1: Introduzir contexto
        r1 = await runner.run_async(
            session_id="student-ada",
            user_message="Hi! My name is Ada and I am learning async generators.",
            turn_timeout=30.0,
        )
        print("Turn 1:", r1.content)

        # Turno 2: O contexto é recuperado automaticamente do SQLiteSessionStore
        r2 = await runner.run_async(
            session_id="student-ada",
            user_message="What was my name and what topic am I studying?",
            turn_timeout=30.0,
        )
        print("Turn 2:", r2.content)

if __name__ == "__main__":
    asyncio.run(main())
```

## 4. Testes Interativos no Terminal (`CLIChannel`)

Você pode testar qualquer `Runner` interativamente no terminal sem escrever um loop manual conectando o `CLIChannel`:

```python
from chatflow_agent import Agent, CLIChannel, Runner

agent = Agent(
    name="LocalHelper",
    instructions="You are a helpful CLI assistant.",
    model="gemini-2.5-flash",
)

runner = Runner(starting_agent=agent)
cli = CLIChannel(session_id="local-dev-session", prompt_prefix="\nYou: ")
cli.attach(runner)

if __name__ == "__main__":
    # Digite mensagens no console; use '/reset' para limpar o histórico ou 'exit' para sair
    cli.run()
```
