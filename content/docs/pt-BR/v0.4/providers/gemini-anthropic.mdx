Google Gemini e Anthropic Claude representam duas das famílias de modelos de fronteira mais capazes para fluxos de trabalho agênticos. O `chatflow-agent` disponibiliza motores dedicados e nativos para ambos os provedores, otimizados para baixa latência, zero bloqueio de SDKs e chamada confiável de ferramentas.

---

## Google Gemini Engine

O `GeminiEngine` comunica-se diretamente com a API Gemini Developer (`v1beta`) do Google para executar conversas de múltiplos turnos e chamadas de função.

<Callout type="info" title="Variante Suportada da API Gemini">
O `GeminiEngine` suporta a **Gemini Developer API** (chaves de API do Google AI Studio). O Google Cloud Vertex AI não é suportado por este motor.
</Callout>

### Autenticação e Credenciais

O motor lê as credenciais das seguintes fontes, em ordem de prioridade:
1. `api_key` passada diretamente para `GeminiEngine(api_key="...")`, ou `Agent(api_key="...")` junto com `provider="gemini"`. Sem um provider, um agente com modelo Gemini executado através de um `Runner` usa o motor do Runner (criado a partir de `Runner(api_key=...)` ou do ambiente), e a `api_key` do próprio agente não é utilizada.
2. Variável de ambiente `GEMINI_API_KEY`.
3. Variável de ambiente `GOOGLE_API_KEY`.

Por padrão, a chave de API é transmitida através do cabeçalho HTTP seguro `x-goog-api-key`. Passar `api_key_in_query=True` transmite a chave como parâmetro de consulta `?key=`:

```python
import os
from chatflow_agent import Agent, Runner
from chatflow_agent.core.engines.gemini import GeminiEngine

# Recomendado: Autenticação segura via cabeçalho
gemini_engine = GeminiEngine(
    api_key=os.environ.get("GEMINI_API_KEY"),
    timeout_seconds=30.0,
    max_retries=3,
)

assistant = Agent(
    name="GeminiAssistant",
    model="gemini-2.5-flash",
    engine=gemini_engine,
    instructions="Provide concise, accurate answers.",
)
```

### Pool de Conexões e Arquitetura Zero-SDK

  <VersionBadge version="0.3.4" status="stable" />
</div>

A implementação do Gemini passou por uma reformulação arquitetural significativa entre as versões:

* **Na `v0.3.4` (Estável):** O motor importava o SDK oficial `google-genai` do Google (`from google import genai`), exigindo a instalação da biblioteca de cliente externa.
* **Na `v0.4.0rc1` (Pré-lançamento):** O motor foi totalmente reescrito usando `httpx` assíncrono nativo contra `https://generativelanguage.googleapis.com/v1beta`. Isso elimina dependências pesadas e viabiliza o **pool de conexões** entre os turnos dos agentes:

```python
# [min-version: 0.4.0rc1]
# [no-exec: requires real gemini api key]
import asyncio
from chatflow_agent import Agent, Runner

agent = Agent(
    name="Assistant",
    instructions="Provide concise, accurate answers.",
    model="gemini-2.5-flash",
)
runner = Runner(starting_agent=agent)

async def main():
    # 'async with runner:' mantém as conexões HTTP ativas entre os turnos
    async with runner:
        res1 = await runner.run_async("session-1", "What is quantum computing?")
        res2 = await runner.run_async("session-1", "Summarize in 3 bullet points.")
        print(res2.content)

asyncio.run(main())
```

### Configuração de Proxy Customizado

Para rotear requisições do Gemini através de um proxy corporativo ou gateway, defina a variável de ambiente `GOOGLE_GEMINI_BASE_URL`:

```bash
export GOOGLE_GEMINI_BASE_URL="https://gemini-proxy.internal.corp"
```
O motor anexa automaticamente `/v1beta` à URL base.

## Anthropic Claude Engine

O `AnthropicEngine` oferece integração nativa com o Claude 3.5 Sonnet, Claude 3.5 Haiku e Claude 3 Opus da Anthropic através da Messages API.

### Autenticação e Cabeçalhos

Requisições para a Anthropic exigem o cabeçalho `x-api-key` e o cabeçalho `anthropic-version` (o padrão é `"2023-06-01"`).

O motor obtém credenciais de:
1. `api_key` passada explicitamente para `AnthropicEngine(api_key="...")` ou `Agent(api_key="...")`.
2. Variável de ambiente `ANTHROPIC_API_KEY`.

<Callout type="warn" title="Regra de Segurança de Credenciais">
Assim como o `OpenAIEngine`, o `AnthropicEngine` envia `ANTHROPIC_API_KEY` exclusivamente para o endpoint oficial `https://api.anthropic.com/v1`. Se você especificar uma `base_url` customizada, deverá fornecer `api_key` explicitamente.
</Callout>

```python
import os
from chatflow_agent import Agent
from chatflow_agent.core.engines.anthropic import AnthropicEngine

claude_engine = AnthropicEngine(
    api_key=os.environ.get("ANTHROPIC_API_KEY"),
    timeout=60.0,
)

editor = Agent(
    name="Editor",
    model="claude-3-5-sonnet-20241022",
    engine=claude_engine,
    instructions="Edit and refine technical documentation.",
)
```

### Tentativas Automáticas e Backoff com Jitter

O `AnthropicEngine` repete automaticamente requisições em caso de restrições de taxa (`429 Too Many Requests`), erros temporários de servidor (`500`, `502`, `503`, `504`), o status de sobrecarga da Anthropic (`529`) e erros de conexão, aplicando recuo exponencial com jitter:
* **Tentativas Máximas:** 3 novas tentativas após a primeira (até 4 requisições).
* **Intervalo Base:** 1.0 segundo.
* **Intervalo Máximo:** 10.0 segundos.

Esses valores são fixos na v0.4.0rc1; não são parâmetros do construtor. Quando uma resposta repetida inclui um cabeçalho `Retry-After` numérico, esse valor substitui o intervalo exponencial, mas a espera continua limitada a 10 segundos, de modo que um intervalo solicitado mais longo não é totalmente respeitado.

## Colaboração Multi-Modelo de Agentes

Uma das principais vantagens do `chatflow-agent` é a capacidade de compor enxames em que diferentes agentes utilizam modelos de base distintos de acordo com suas especialidades:

```python
from chatflow_agent import Agent, Runner
from chatflow_agent.core.engines.gemini import GeminiEngine
from chatflow_agent.core.engines.anthropic import AnthropicEngine

gemini = GeminiEngine()
claude = AnthropicEngine()

researcher = Agent(
    name="Researcher",
    model="gemini-2.5-flash",
    engine=gemini,
    instructions="Gather facts quickly using Gemini's high-throughput processing.",
)

synthesizer = Agent(
    name="Synthesizer",
    model="claude-3-5-sonnet-20241022",
    engine=claude,
    instructions="Synthesize gathered facts into clear, well-structured prose.",
)

# Conectar agentes via handoffs
researcher.add_handoff(synthesizer)
synthesizer.add_handoff(researcher)

runner = Runner(starting_agent=researcher)
```

Neste enxame:
1. O **Researcher** opera com o Gemini 2.5 Flash para ingestão rápida e busca de alta vazão.
2. Assim que os dados são coletados, a sessão é transferida para o **Synthesizer** no Claude 3.5 Sonnet.
3. Mensagens históricas e IDs de chamada de ferramenta são normalizados automaticamente, evitando incompatibilidades de formato entre os diferentes provedores.
